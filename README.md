# 📊 Business Performance Analysis & MIS Dashboard

## 📌 Project Overview
This project focuses on analyzing business performance using Microsoft Excel. It presents sales information through an interactive dashboard to help understand revenue, profit, orders, customer activity and regional performance.

## 🎯 Project Objectives
- Analyze overall business performance.
- Monitor total revenue and profit.
- Track orders and customer activity.
- Compare monthly and yearly performance.
- Analyze sales across product categories and regions.
- Support business decision-making through dashboard reporting.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- GETPIVOTDATA
- Excel Formulas
- Data Analysis
- Dashboard Visualization

## 📂 Workbook Structure

### 1. Sales Data
Contains the sales records used for analysis.

### 2. PIVOT
Contains pivot-table summaries and KPI calculations.

### 3. Dashboard
Presents the business performance dashboard and key performance indicators.

## 📈 Key Performance Indicators (KPIs)
- Total Revenue
- Total Profit
- Total Orders
- Total Customers
- Profit Margin
- Revenue Target
- Actual Performance
- Performance Gap

## 🔍 Analysis Areas
- Monthly and yearly revenue analysis
- Profit analysis
- Order analysis
- Customer analysis
- Product category performance
- Regional and state-wise sales performance

## 📁 Project File
`BUSINESS PERFORMANCE DASHBOARD.xlsx`

## 🚀 How to Use
1. Download the Excel workbook from this repository.
2. Open it using Microsoft Excel.
3. Navigate to the Dashboard sheet.
4. Explore the available performance metrics and analysis.
